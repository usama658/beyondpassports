# Destination photo manifest, Schengen grid previews

Date: 2026-10-07. Covers all 29 destination photographs used by the `grid-za-*` preview files in `ukv-app/storage/previews/`.

Every image is hosted on Wikimedia Commons and served from a `960px-` thumbnail on `upload.wikimedia.org`. Licences are CC0, CC BY or CC BY-SA only. No NonCommercial or NoDerivatives image is used, because the cards crop the photo and overlay text on it, which is commercial adapted use.

Attribution is legally required for every CC BY and CC BY-SA image here. The footer credit line in each preview file carries the full list, and must stay in place if a photo is reused anywhere else.

## Files that use this set

`grid-za-p1`, `grid-za-p2`, `grid-za-l1`, `grid-za-l2`, `grid-za-l3`, `grid-za-t1`, `grid-za-t2`, `grid-za-t3`, `grid-za-r1`, `grid-za-r2`, `grid-za-r3`. The `r2` and `r3` files repeat the six Popular destinations in a second group, so each photo there appears twice.

## Notes on specific credits

- Lithuania: the Commons `Artist` field reads `BigHead`, the uploader's username. The file name and description credit Augustas Didzgalvis, so the footer uses the person's name.
- Malta: the Commons `Artist` field is a block of boilerplate that asks to be credited as `Photo: Anton Zelenov`. The footer uses Anton Zelenov.
- Bulgaria: Commons states `Plamen Agov (user:MrPanyGoff)`. The footer uses Plamen Agov.
- Sweden: Commons states `Julian Herzog (Website)`. The footer uses Julian Herzog.
- Romania: the capital-city options on Commons were weak at editorial quality (the Palace of the Parliament shots are distant or dominated by car parks), so Brasov Council Square seen from Tampa is used instead.
- The previous shared placeholder, a Salisbury Cathedral facade by Giuseppe Pinto, is no longer used anywhere and its credit has been removed.

## Verification performed

- Pixel dimensions read from the Commons API, not guessed from search thumbnails. Every image is landscape.
- Every 960px URL confirmed to return HTTP 200 with `Content-Type: image/jpeg`.
- Every candidate was downloaded and reviewed as a cropped card to check the subject is architecture, cityscape or landscape, with no people as the main subject, no flags and no passport imagery. Four first-round picks failed that review (Austria, Denmark, Liechtenstein, Romania) and were replaced.
- All eleven preview files checked in Chromium at 1280px and 375px: every image element loads with naturalWidth above zero, `width`/`height` attributes match the served pixels, and no page scrolls horizontally.
